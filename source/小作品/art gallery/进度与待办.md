## 项目结构（实际）

```
art gallery/
├── index.html          # 主站单文件（Tailwind CDN + 内联 JS/CSS）
├── ai-guide.html       # AI 导览 + 猜流派 Quiz（独立单文件，需 Anthropic API key）
├── data/styles.json    # 单一数据源（12 流派）
├── public/artworks/<id>/   # 本地图片（21 张，已压到 ≤1600px）
├── IMAGE_AUDIT.md      # 图片版权审计报告 + 署名清单
└── .claude/launch.json # 预览配置（指向 /tmp/artgallery 的 node 临时服务，仅本地预览用）
```

### 关键架构
- **数据加载**：`index.html` 的 `loadData()` 先 `fetch('data/styles.json')`（HTTP 部署读实时数据），失败则回退到内联 `<script id="styles-data">` 快照（支持 file:// 双击打开）。
- ⚠️ **改了 `data/styles.json` 后必须刷新内联快照**，否则 file:// 打开看到旧数据。重新注入命令：
  ```bash
  python3 - <<'PY'
  import re,json
  html=open('index.html',encoding='utf-8').read()
  data=open('data/styles.json',encoding='utf-8').read()
  html=re.sub(r'(<script type="application/json" id="styles-data">)(.*?)(</script>)',
              lambda m:m.group(1)+data+m.group(3), html, count=1, flags=re.S)
  open('index.html','w',encoding='utf-8').write(html)
  PY
  ```
- **路由**：`route()` 处理 `#/`(首页)、`#/<id>`(展厅)、`#/timeline`、`#/compare/<a>/<b>`。
- **部署**：同 portfolio，push main → Cloudflare Pages 自动上线（纯静态）。
