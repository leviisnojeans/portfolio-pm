## T0 · 项目脚手架

**目标**：建好可运行的空项目。
**做什么**：`create-next-app`（App Router + TypeScript + Tailwind）；安装 `framer-motion`、`lucide-react`、`clsx`；初始化 shadcn/ui。用当前版本，不锁旧版。
**验收标准**
- [ ] `npm run dev` 起得来，首页空白页正常渲染
- [ ] Tailwind 类生效；TS 严格模式开启
- [ ] framer-motion / lucide-react 可 import 不报错

---

## T1 · 数据层

**目标**：让全站从 `styles.json` 取数，组件零硬编码。
**产出**：`data/styles.json`、`lib/types.ts`、`lib/styles.ts`
**做什么**
- 把 `styles_6月22日.json` 放进 `data/styles.json`。
- `types.ts`：按 schema 写 `Style` 类型（`comparison` 五字段、`visualDNA[]`、`relations`、`eastWest{west,east}`、`coverArtwork{image,rights,...}`、`isDark?`、`themeColor` 等）。
- `styles.ts`：
  - `getPublishedStyles()`：过滤 `status==='published'`，按 `period.start` 升序。
  - `getStyleById(id)`、`getRelated(id)`（按 `relatedStyles` 解析成对象）。
  - `getCoverImage(style)`：有 `coverArtwork.image` 返回 URL，否则返回 `null`（由卡片用 `themeColor` 占位）。

**验收标准**
- [ ] 临时测试页能列出 12 个流派的 `nameZh` + `coreLine`，按年代排序（侘寂最早、赛博朋克/解构最晚）
- [ ] `getRelated('bauhaus')` 返回 swiss-style / brutalism 等对象而非 id 字符串
- [ ] 无图流派 `getCoverImage` 返回 null，不报错

## T2 · 设计 tokens 与全局样式

**目标**：博物馆视觉基底就位。
**产出**：`app/globals.css`、`app/layout.tsx`
**做什么**
- CSS 变量：`--paper:#F5F2EC`、`--ink:#2A2622`、`--muted:#8A8278`、`--gold:#B08D4F`。
- 字体：标题 Playfair Display + 中文宋体，正文 Inter（用 `next/font`）。
- `layout.tsx` 包一层 `AmbientBackground`：接收当前焦点流派的 `themeColor`，背景色做 0.6s 缓动过渡；`isDark` 流派整体切深色文字方案。

**验收标准**
- [ ] 衬线标题 / 无衬线正文正确渲染，中英文都正常
- [ ] 手动传入不同 `themeColor`，背景平滑过渡
- [ ] 传入 `isDark:true` 流派，文字/UI 切到深色可读方案

## T3 · Cover Flow 滚筒组件（核心 · 先用 mock 单独做）

**目标**：复刻已确认的滚筒预览交互。
**产出**：`components/CoverFlowCarousel.tsx`、`components/StyleCard.tsx`
**做什么**
- 卡片横排，中心最大；两侧用 `rotateY` 倾斜 + 缩放 + 降透明度（CSS 3D `perspective`+`rotateY`+`translateZ`，不用 Three.js）。
- 导航：鼠标拖拽、滚轮、左右方向键；**松手有惯性减速**。
- `StyleCard`：有图显示作品图，无图用 `themeColor` 纯色占位卡（带流派名）。
- **文字默认全部隐藏**；hover 中央卡时，流派名 / 国家·年代 / `coreLine` / 「LEARN →」从图上淡入，画面轻微放大压暗；两侧卡不响应。
- **触屏无 hover**：滚到中央的卡自动判定聚焦态、常显文字（移动端必须有这条，否则永远看不到信息）。
- 焦点切换时，向上层回调当前流派，驱动 `AmbientBackground` 换 `themeColor`。

**验收标准**
- [ ] 桌面：拖拽/滚轮/方向键都能转动，有惯性
- [ ] 默认无任何文字；hover 中央才浮现，移开消失
- [ ] 触屏（或窄屏模拟）：中央卡常显文字，无需 hover
- [ ] 无图流派显示 themeColor 占位卡，不破版
- [ ] 切换焦点时背景 themeColor 跟随过渡

**产出**：`app/page.tsx`、`components/nav/SiteNav.tsx`
**做什么**：顶部极简导航（Art Museum 字标 + Gallery/Timeline/Compare/About，Compare/Timeline 可先占位）；`CoverFlowCarousel` 接 `getPublishedStyles()` 真实数据；底部进度点 + 向下提示。点击中央卡或「LEARN →」跳 `/[id]`。
**验收标准**
- [ ] 首页用真实 12 流派渲染滚筒
- [ ] 点中央作品进入对应展厅页

## T5 · 展厅详情页（路由）

**目标**：`/[id]` 完整展厅页。
**产出**：`app/[id]/page.tsx`、`components/VisualDNA.tsx`、`components/Timeline.tsx`
**做什么**（顺序即页面结构，对应 PRD 3.2）：全屏 hero（作品/占位 + 压暗 + 流派名落款 + 国家年代 + coreLine）→ 代表作画廊（`masterworks`，空则占位）→ 概述（`origin.thesis`）→ Visual DNA 标签（`visualDNA`，icon 用 Lucide/Tabler 名映射）→ **UI 转化原则**版块（`uiTranslation` 四项）→ **东西方视角**版块（`eastWest.west` / `.east`，east 为空时隐藏）→ 时间线定位（`period` + prev/next）→ 相关流派（`getRelated`，可点跳转）。`generateStaticParams` 用 published id。
**验收标准**
- [ ] 12 个 id 都能打开且不报错
- [ ] east 为空的（新艺术/孟菲斯）东方视角版块自动隐藏，不留空块
- [ ] Visual DNA 图标正确渲染；相关流派可点击跳转
- [ ] 无图流派全程用 themeColor 占位，视觉不破

## T6 · 响应式与打磨

**目标**：达到可展示水准。
**做什么**：移动端滚筒手势（滑动 + 中央聚焦）；图片懒加载与 `next/image`；`isDark` 流派（赛博朋克/装饰艺术）的暗色配色对；页面转场（fade / 长缓动）；占位卡与真实图统一过渡。
**验收标准**
- [ ] 手机宽度下滚筒可用、文字可见（中央聚焦逻辑生效）
- [ ] 切到 isDark 流派整屏转暗且文字可读
- [ ] 首屏与详情页转场顺滑，无闪烁
- [ ] Lighthouse 无明显可访问性/性能红线

---

## MVP 完成定义（Definition of Done）

1. 打开首页 → 滚筒展示 12 流派、默认无字、hover/聚焦出信息、背景随焦点变色。
2. 点任意作品 → 进入该流派展厅，五大版块（概述/Visual DNA/UI 转化/东西方/相关）齐全。
3. 全程数据来自 `styles.json`，新增流派只需加数据 + 图，零改组件。
4. 桌面与移动端均可用；无图流派用 themeColor 占位不破版。

> 完成 MVP 后进 V2：对比模式（五轴）、时间线全景、AI 导览 + Quiz（接 Claude API，作为简历的 AI 作品亮点）。
