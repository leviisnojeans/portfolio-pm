## 1. 产品定位

把 Levi「艺术风格研究系列」的 12 个**设计风格**（注意：是设计/视觉语言，非油画流派）做成一个可浏览、可对比、可持续扩展的数字博物馆。差异化来自三点，都是别的艺术站没有的：

- **UI 转化视角**：每个流派都讲「如何落到界面设计」——这是 PM 视角的独有切口。
- **东西方对照**：每个流派一个签名版块，呈现同一套语言在东西方不同的权力结构里如何被使用。
- **结构化对比**：用「对秩序的态度 / 对装饰的态度 / UI 应用难度」三轴，让任意两个流派可自动对位。

核心体验原则：**Image First → Emotion Second → Knowledge Third**（先感受，再理解）。

## 3. 页面规格

### 3.1 首页 · 3D Museum Carousel（Cover Flow）
- 运动模型 = Cover Flow（卡片横排、中心最大、两侧 `rotateY` 倾斜 + 缩放 + 降透明度），叠加圆柱景深与惯性。纯 CSS 3D transform（`perspective` + `rotateY` + `translateZ`）实现，不上 Three.js。
- 滚筒滚的是**代表作（cover artwork）**，不是流派名。
- **默认不显示任何文字**；hover 中央主图时，流派名 / 国家·年代 / `coreLine` / 「LEARN →」从图上淡入，画面轻微放大压暗。两侧卡片不响应。
- **触屏无 hover**：滚到中央的作品自动判定为聚焦态、常显文字。此规则必须实现，否则移动端永远看不到信息。
- **环境氛围**：背景与环境光随焦点流派的 `themeColor` 过渡（暖→冷→暗）。`isDark: true` 的流派（赛博朋克、装饰艺术）整站切到暗色，需单独配色对。

### 3.2 展厅详情页
全屏 hero（代表作 + 压暗 + 流派名落款）→ 先甩代表作画廊（`masterworks`）→ 概述（`origin`，≤50 字）→ Visual DNA 标签（`visualDNA`，icon + label）→ **UI 转化原则**版块 → **东西方视角**版块 → 时间线定位 → 相关流派（`relatedStyles`）。

### 3.3 对比模式（Compare）
- 左右分屏，向中央「对位轴」收拢，形成 face-off。
- **固定五轴**（所有流派都按此填，任意两个可自动对位）：
  `年代·理念` / `对秩序的态度` / `对装饰的态度` / `UI 应用难度` / `核心情绪`
- 能可视化就不写字：`comparison.palette` 渲染成色卡；秩序/装饰态度用枚举值，可自动聚类「态度相同/相反」。
- 顶部流派可切换；支持「换一组对比」。

### 3.4 时间线全景
横向时间轴，按 `period.start` 自动排序。注意本系列**跨度极大**（侘寂 14C → 赛博朋克当代），建议用「对数/分段」时间轴或按世纪分组，否则早期会挤成一团。可叠加按 `orderStance` 聚类的视图，复刻你索引里的「对秩序的态度」分组。

## 4. 设计 Tokens

- **配色**：暖象牙白底（`#F5F2EC`）、近黑暖灰文字（`#2A2622`）、克制金色强调（`#B08D4F`）。焦点区域注入流派 `themeColor`。
- **字体**：标题用衬线（Playfair Display 类），正文用无衬线（Inter）。中文标题可配思源宋体。
- **动效**：淡入、缓慢缩放、模糊到清晰、视差、长缓动。博物馆气质——避免花哨。
- **留白**：大间距、安静、作品永远是主角。

## 5. 数据模型与扩展机制

单一数据源 `styles.json`，UI 全部从中渲染，**不在组件里写死任何流派**。每条记录结构见数据文件；关键字段：`id / name / nameZh / coreLine / period / themeColor / origin / visualLanguage / visualDNA / uiTranslation / eastWest / comparison / relations / relatedStyles / coverArtwork / masterworks / status`。

**新增一个流派的完整流程（零代码改动）：**
1. 往 `styles[]` 追加一条同结构对象；
2. 图片放进 `/public/artworks/<id>/`；
3. `status` 设为 `published`（没准备好就留 `draft`，前台自动隐藏）。

之后：滚筒自动多一张卡、时间线自动插入正确位置、对比模式自动可选、`relatedStyles` 按 id 自动连线。`relations` 与 `relatedStyles` 全用 id 引用，改名不断链。

枚举值（保证对比可自动化）：
- `orderStance`：建构 / 自然 / 嘲讽 / 暴露 / 崩溃秩序
- `decorationStance`：装饰即目的 / 装饰是罪恶 / 装饰是武器 / 无需装饰 / 装饰即信息过载 / 装饰即奢华
- `uiDifficulty`：直接可用 / 需要转译 / 哲学层面

## 6. 图片版权策略（设计风格比油画复杂，分级处理）

| 分级 | 流派 | 取图来源 |
|---|---|---|
| 公有领域，可直接用 | 浮世绘、构成主义、新艺术（Mucha）、侘寂（古画/古籍） | Met Open Access (CC0)、Wikimedia |
| 建筑摄影，含摄影师版权 | 粗野主义、解构主义、装饰艺术、新艺术（高迪） | 找 CC 授权图，或上海实景自摄 |
| 仍在版权期，需谨慎 | 孟菲斯（Sottsass 物件）、瑞士国际主义海报、波普艺术 | 找授权 / 用风格化示意 / 字体样张替代 |
| 无现成公有图 | 赛博朋克 | 自生成 AI 示意图 |

数据文件里每个 `coverArtwork.rights` 已标注。**上线前务必逐张核对**，这是视觉优先项目最大的隐性风险。

## 7. 技术栈

Next.js 15 (App Router) + TypeScript + TailwindCSS + Framer Motion + shadcn/ui + Lucide。JSON 数据起步，后续可迁 Supabase。需做图片优化、响应式、暗色模式、SEO、无障碍。
